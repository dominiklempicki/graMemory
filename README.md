# Memory

**Gra Memory** to popularna gra karciana polegająca na odkrywaniu par identycznych kart. Gra rozwija pamięć, spostrzegawczość oraz strategiczne myślenie.

## 🎮 Cel gry

Celem gry jest odkrycie jak największej liczby pasujących par kart.

Gracz, który zdobędzie więcej punktów, czyli znajdzie więcej par, wygrywa.

1. Pobierz wersję programu odpowiednią dla swojego systemu.
2. Uruchom pobrany program.
3. Wybierz sposób rozpoczęcia gry.
4. Postępuj zgodnie z instrukcjami wyświetlanymi w programie.

## 📖 Zasady gry

### Opcja 1 — rozpoczęcie nowej gry

1. Gracze nadają sobie pseudonimy.
2. Ustalany jest:
   * rozmiar kart w formacie `n × n`,
   * zestaw znaków używanych do tworzenia kart,
   * liczba par kart.
3. Karty są generowane z losowo wybranymi znakami.
4. Układ kart jest zapisywany do pliku, dzięki czemu można wznowić rozgrywkę, jeśli nie została zakończona.
5. Pod kartami widoczne są informacje o punktach oraz aktualnym graczu.
6. Gracze na zmianę podają numery kart, które chcą odkryć.
7. Jeśli odkryte karty tworzą parę, gracz otrzymuje punkt i może kontynuować.
8. Jeśli karty nie pasują do siebie, kolej przechodzi na drugiego gracza.
9. Po odkryciu wszystkich kart gra zostaje zakończona i wyłaniany jest zwycięzca.

### Opcja 2 — wczytanie zapisanej gry

Program umożliwia odtworzenie ostatniej **niezakończonej rozgrywki** zapisanej wcześniej do pliku.

### Opcja 3 — gra domyślna

Tryb przeznaczony dla osób, które chcą szybko rozpocząć rozgrywkę bez konfigurowania wszystkich parametrów.
